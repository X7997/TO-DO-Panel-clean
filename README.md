# TO-DO Panel: 极客桌面贴顶工作台

> **Windows 贴顶极简 Bento 工作台** — 融合 Mac 刘海灵动形态与艾维·利时间管理法则，为硬核开发者打造的零阻力桌面 HUD。

![TO-DO Panel](assets/banner.png)

---

## 核心设计与创新特性

### 1. 屏顶灵动药丸条 (Notch Pill)
- **极小面积常驻**：吸附在 Windows 屏幕正上方（280 × 38px），透明毛玻璃质感，完全不遮挡全屏代码与游戏。
- **三点式微能量槽**：屏顶直接显示今日前 3 项核心任务的完成进度（蓝光闪烁代表进行中，绿光代表完成）。
- **磁吸拉伸反馈**：鼠标靠近时微向下延伸 4px，单机平滑下弹展开 1080×630 Bento 工作台。

### 2. 艾维·利核心前三高亮 (Ivy-Lee Focus)
- **认知减负**：任务列表永远**只高亮前 3 项核心任务**（霓虹微光、大字号、醒目标签）。
- **下一发已上膛**：第 4 项作为独立就绪槽（Next Up）静候顶替。
- **候补低对比灰**：第 5 项及以后为低饱和度灰色抽屉，避免任务过多带来的焦虑压迫感。
- **1.5秒爽感划线与飞移**：勾选任务后触发 1.5 秒翡翠绿划线光晕，随后沿贝塞尔曲线**向左滑移缩入本周战利品池**，候补任务瞬间平滑顶上点亮！

### 3. 左栏：项目工坊与本周战果池 (Trophies & Workspaces)
- **直达工作区**：点击项目卡片上的 `[💻]` 按钮，直接唤起 VS Code 或系统资源管理器定位该项目。
- **GitHub 级代码安全体检 (`🧹`)**：
  - 扫描工作区内的临时测试脚本（`test_*.py`, `temp_*`）与庞大构建缓存（`__pycache__`, `.tmp`）；
  - **绝不物理碎纸**：一键安全打包移至 `.archive/cleanup_<时间戳>/` 备份，杜绝误删。
- **7日战果热力刻度 + 撤回复活**：
  - 记录过去 7 天斩获的战绩；
  - 提供“后悔药”机制：点击 `[撤销]` 随时将战果复活并推回今日待办。

### 4. 极速单行录入语法 (NLP Quick Add)
在输入框输入任务时支持快捷标记：
- `#P33` 或 `#p18`：自动匹配并关联至对应项目；
- `!1` 或 `!`：强行置顶插队至今日专注第 1 位。
- 例如：`编写串口DMA驱动 #P33 !1` ➔ 敲回车即刻就绪，手不离键盘。

### 5. 右栏：技能雷达与 3D 纯净速记草稿 (Radar & Scratchpad)
- **技能树对齐雷达**：对齐 `Q:\Obsidian_KB` 技术栈（ESP32, K230, 机器视觉, 桌面应用），推荐高价值开源库，支持一键 `[+ 入待做]`。
- **3D 纸牌翻转**：一键翻转为纯净 Markdown 调试草稿垫，实时自动保存。

### 6. 晚间 20:30 暮色复盘审阅官 (Twilight Audit)
- 到了晚上 20:30，顶部边框亮起温暖的暮色琥珀金微光；
- 点击展开今日战果复盘、项目推进审计、以及与 Obsidian 知识库的原子经验沉淀提醒。

## 快速运行

```powershell
# 1. 进入目录
cd q:\Todo

# 2. 启动贴顶工作台
npm start

# 3. 运行自动化端到端冒烟测试
npm test
```
